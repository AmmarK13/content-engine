Privacy Policy

Avatar Harness POC

Avatar Harness POC is an internal testing tool that uploads AI-generated videos to YouTube via the YouTube Data API v3.

Data collected

YouTube OAuth tokens, stored temporarily for the duration of a test session and not persisted to any external service.

Data sharing

None. No user data is collected, stored, or shared with third parties.

Synthetic media disclosure

Videos produced by this pipeline that feature an AI-generated avatar are labeled as containing synthetic media at the time of upload, in line with YouTube's disclosure requirements.
